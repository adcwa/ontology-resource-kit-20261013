# 官方获取来源

每项资源的发布/维护方、权威类型、获取权限和官方入口。优先使用标准组织、发布方官网和官方仓库。

**来源由整理者依据公开信息选定，未在制作环境逐项访问核验；以发布方页面为准。** 标注付费或需许可的项目不会被工具自动下载。
